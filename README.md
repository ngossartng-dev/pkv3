# Poker Academy - Package Complet MVP

Ce fichier ZIP contient la structure complète des dossiers et des fichiers pour démarrer immédiatement votre application :
- `lib/main.dart` : Point d'entrée de l'application Flutter (Splash Screen Quinte Flush, Age Gate +18 ans, Dashboard Bankroll).
- `lib/views/simulation_table_screen.dart` : Écran complet de la table de tournoi avec les bots, le tapis ovale, les cartes à 4 couleurs, le curseur de sizing et le pop-up de sanction du Professeur Virtuel.
- `backend/bot_engine.py` : Logique de décision comportementale des bots (Nit, Calling Station, Maniac).

### Comment l'utiliser sur GitHub :
1. Téléchargez et décompressez cette archive sur votre ordinateur.
2. Créez un dossier sur votre PC, glissez-y ces dossiers (`lib/`, `backend/`, `README.md`).
3. Envoyez le tout sur votre dépôt GitHub. Vous avez ainsi une base propre et organisée !
